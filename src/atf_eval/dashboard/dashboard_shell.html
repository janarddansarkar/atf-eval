What each metric means

plain-English, then the formula

ATF blends five independent metrics into one fidelity score. Each one answers a different question about the agent's run — a metric whose evidence the trace does not record reports N/A, never a zero (METRICS.md Frozen Rule 11).

NTS

Node Traversal Similarity

Did the agent take the right steps, in the right order, without skipping any or adding extra ones?

30% of ATF
formula
NTS = .40×Coverage + .30×Precision + .30×Order
Matched nodes: exact, position-aware
  sequential (LCS) alignment
Order: LCS / max(|expected|, |observed|)
STS

State Transition Similarity

Did the right facts about the conversation change at the right time — e.g. "customer_verified: false → true"?

30% of ATF
formula
STS = .70×Transition Accuracy + .30×Order
Accuracy: key+old+new all match, compared
  within LCS-aligned nodes (node-level state)
Order: LCS over full (key, old, new)
TIS

Tool Invocation Similarity

Did the agent call the right backend tools, with the right inputs, in the right order?

15% of ATF
formula
TIS = .25×Coverage + .20×Precision
    + .25×Identity + .20×Input + .10×Order
Aligned within LCS-aligned nodes when the
  trace supports node association (else per
  turn); Identity = correct / aligned pairs;
  Input over matched (same-tool) pairs
RS

Routing Similarity

Given what the customer said, did the agent choose the right conversational direction? Judged by an LLM, not just field-matching.

10% of ATF
formula
RS = .70×Semantic Judge Score + .30×Order
Order over path decisions; no judge verdict
  ⇒ routing not evaluable ⇒ RS N/A
OS

Outcome Similarity

Did the conversation land on the correct final result, with the correct details (amount, frequency, duration)?

15% of ATF
formula
OS = .50×Identity + .30×Attributes + .20×Completion
Completion: required outcome attributes
  achieved / required (N/A if none declared)
ATF

Agent Trajectory Fidelity

The single composite score: a weighted blend of all five above. Any metric with no evidence is excluded and the rest re-weighted — never coerced to zero.

the headline number
formula
ATF = .30NTS + .30STS + .15TIS
    + .10RS + .15OS  (renormalized over
    whichever groups are applicable)

LLM & multimodal evaluation

METRICS.md Part B · Groups 1-5

A second, independent set of 32 metrics scored by an LLM judge instead of a formula: response quality, grounding, safety/policy, conversation quality, and voice/multimodal. Each keeps its native scoring (1–5, Pass/Fail, -2..+2, count+severity, category+confidence — METRICS.md §19: no cross-metric normalization), so there is no blended score here the way NTS/STS/TIS/RS/OS blend into ATF. Full results for every run are in the LLM & Multimodal Evaluation section of that run's panel below, grouped exactly as METRICS.md groups them.

G1

Response Quality

Relevance, Correctness, Completeness, Helpfulness, Question Quality.

G2

Grounding & Knowledge

Faithfulness, Groundedness, Hallucination, Citation/Evidence Accuracy.

G3

Safety, Policy & Compliance

Policy Compliance, AI Safety, Refusal/Escalation Quality.

G4

Conversation Quality

Coherence, Empathy, Intent Understanding, Repetition, Effort, Friction, Sentiment.

G5

Voice / Multimodal

13 metrics needing audio/timing evidence (interruptions, prosody, latency, disconnection, …). N/A on a text-only trace — never a false score.
